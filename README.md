# 微信签到抽奖 Web 项目

本项目用于内网活动现场：电脑启动服务，大屏展示二维码，来宾用微信扫码签到，后台管理奖项并发起滚动抽奖。

内网图文使用手册：[PDF 阅读版](docs/user-guide/微信签到抽奖系统使用手册.pdf) / [Word 编辑版](docs/user-guide/微信签到抽奖系统使用手册.docx)。签到字段、大屏设置和内定人员操作以本文为准。

对外开放请按服务器系统选择 [Linux 公网部署指南](docs/linux-deployment.md)或 [Windows 公网部署指南](docs/windows-deployment.md)。来宾用微信扫码授权后取得微信头像，再填写姓名和手机号完成签到。下方默认启动方式用于可信内网。

## 启动

```bash
npm install
npm start
```

默认端口：`3000`

打开：

- 登录页：http://localhost:3000
- 后台：http://localhost:3000/admin
- 签到展示：http://localhost:3000/screen/checkin
- 抽奖大屏：http://localhost:3000/screen/lottery
- 大屏设置：http://localhost:3000/screen/settings（独立设置密码）
- 手机签到：http://localhost:3000/checkin

同一局域网手机访问时，用服务启动后打印的 `http://本机IP:3000` 地址。
如果电脑用 `localhost` 打开后台或大屏，系统会优先把签到二维码生成为局域网 IP 地址；也可以通过 `PUBLIC_URL=http://本机IP:3000 npm start` 手动指定。

## 默认密码

- 后台：`admin123`
- 大屏：`screen123`
- 大屏设置：`settings123`（仅内网默认值）

在项目根目录的 `.env` 中设置 `SETTINGS_PASSWORD` 并重启服务，即可更换大屏设置密码。设置密码须与后台和大屏密码不同。登录后台后再登录大屏设置，可修改内网后台和大屏密码。

## 已实现能力

- 独立签到展示页：二维码、签到人数、头像墙和最近签到实时更新。
- 后台「签到管理」可以开始或暂停签到。暂停时手机页面与提交接口都会停止接收签到；微信授权未配置时，后台单独显示配置状态，不会因开始签到而跳过微信授权。
- 独立抽奖页：选择奖项和人数，开始后持续播放头像滚动动画，点击停止后揭晓中奖人。
- 微信扫码签到入口，二维码默认使用局域网签到地址。
- 默认使用内网表单签到，姓名和手机号必填。头像可上传，也可自动生成姓名头像，无需公众号或公网域名。
- 访问 `/screen/settings`，用独立设置密码登录后调整头像墙、Logo 和二维码的位置与大小。签到和抽奖大屏不提供设置入口。
- 签到大屏上的二维码可直接拖动，右下角手柄可缩放，松手自动保存。大屏账号只能调整二维码布局，其他设置仍需独立设置密码。
- 新签到头像先在大屏中央展示，再汇入头像墙。球形滚动和星环排列使用带透视的三维旋转。后台签到列表保留头像翻转提示，编辑资料不会重新播放入场动画。
- 默认奖项使用球形滚动，抽奖头像沿球面转动。每个奖项还可单独选择环绕、头像矩阵或文字造型。
- 中奖弹窗关闭后，结果保留在当前奖项的抽奖结果中；切换一、二、三等奖时，只显示对应奖项的记录。
- 抽奖结果和展开名单均按当前奖项筛选，后台数据导出保留所有奖项。
- 签到人员默认只参加随机抽奖。在后台「抽奖设置」的对应奖项中选人并点击「添加内定」，才会进入内定名单。点击人员右侧的「删除」可取消该奖项的内定资格，签到记录会保留。
- 签到数据和中奖数据可导出 Excel。

`/screen` 兼容旧版抽奖入口。两个大屏页面使用相同的大屏密码，底部导航可互相切换。

## 项目目录

- `src/server.js`：后端服务、数据接口、实时同步、Excel 导出。
- `src/public/`：前端页面、大屏、后台、手机签到。

- `data/store.json`：运行后自动生成的活动数据。

## 内网扫码签到

默认签到方式是“内网填写姓名与头像”，可在 `/screen/settings` 的“签到方式”中选择。

1. 服务器或电脑启动项目，并放行服务端口（默认 `3000`，本地预览使用 `3100`）。
2. 手机连接能访问服务器的现场 Wi-Fi；访客隔离、防火墙规则不能阻止手机访问服务。
3. 打开签到展示页，手机用微信扫一扫扫描二维码。
4. 来宾填写姓名和手机号，可选上传照片。未上传照片时使用自动生成的姓名头像。
5. 提交后自动上墙并进入抽奖名单。用同一浏览器再次打开可查看签到结果、修改姓名、手机号和头像。

照片在浏览器内裁成方形、压缩到最长 `512` 像素后上传到本地服务器。支持 JPG、PNG、WebP、GIF，原图不超过 `12 MB`，生成的上传文件不超过 `2 MB`。

内网模式用浏览器 Cookie 识别来宾。同一浏览器重复提交会更新同一条记录，升级前用旧访客标识登记的记录保留，来宾首次使用新版时需重新登记。后台可查看和导出手机号，大屏名单隐藏手机号。

纯内网签到不会读取微信头像和昵称。手机页面、照片存储、签到数据和大屏同步均由本项目提供，不依赖外部服务。

## 旧版微信授权

以下配置仅用于兼容旧版。公网部署请按 [Linux 公网部署指南](docs/linux-deployment.md)或 [Windows 公网部署指南](docs/windows-deployment.md)设置。

在「大屏设置」将签到方式切换为「微信网页授权」后，来宾先授权获取微信头像和昵称，再填写姓名和手机号完成签到。同一公众号下的历史微信签到可按已授权身份补填资料。

启动前设置以下环境变量：

```bash
WECHAT_APP_ID=你的公众号AppID \
WECHAT_APP_SECRET=你的公众号AppSecret \
PUBLIC_URL=https://你的公网域名 \
npm start
```

要求：

- `PUBLIC_URL` 必须是微信能访问到的公网 HTTPS 域名。
- 在微信公众号后台配置“网页授权域名”，域名与 `PUBLIC_URL` 保持一致。
- 回调地址为：`PUBLIC_URL/wechat/oauth/callback`
- 授权范围为 `snsapi_userinfo`，用于获取头像和昵称。

只有选择“微信网页授权”且缺少上述配置时，才会提示“微信授权未配置”；默认内网模式不需要这些配置。
